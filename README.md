# Java Day 27 - Average of Array Elements

This Java program calculates the average of all elements in an integer array.

## Example

Array:
```text
10, 20, 30, 40, 50
```

Output:
```text
Sum = 150
Average = 30.0
```

## Concepts Used

- Arrays
- `for` loop
- `numbers.length`
- Addition and division
- Type casting using `(double)`
- Variables

## How It Works

The program stores numbers in an array and uses a `for` loop to calculate their sum. It then divides the sum by the number of elements to calculate the average.

Type casting with `(double)` allows the division to produce a decimal result when necessary.
